# 使用说明

## 记账与分析

在流水页添加收入、支出、转账或退款，按需要选择账本、分类、账户和标签。可以用列表、日历和按月视图回看，通过筛选缩小范围。

分析页包含统计与预算。退款、转账、结余排除及多币种记录遵循各自口径，修改相关设置后请核对预期结果。

常用模板复用录入字段；周期计划生成待确认的期次，适合房租、房贷等重复事项。

## 导入账单

通过数据管理选择支持的支付宝、微信或随手记账单文件，先检查预览，再确认导入。首次迁移建议先备份原数据，并用少量记录验证金额、日期和分类。不要把真实账单上传到公开问题反馈中。

## 管理物品

物品页独立记录照片、购入金额和日期、维修费用与状态。日均成本由日期和费用计算；物品记录不会自动生成记账流水。

## 备份与恢复

账本可以导出 CSV 或完整备份；物品和照片需另做物品备份。完整恢复以副本方式创建内容。WebDAV 使用自己配置的 HTTPS 地址，可选账本前台自动备份。

备份文件包含个人数据，目前未加密。请妥善保管，并定期确认备份能够恢复。卸载应用前先导出账本和物品两类备份。

## 更新

Android 官方安装包可从官网「下载 APK」获取。保持相同签名覆盖升级；更换来源或自行构建前请备份。自行构建默认不检查官方安装包更新。

iOS App Store 下载入口将在正式上架后提供。已加入 TestFlight 的用户以自己实际可安装的版本为准。
