# 数据架构

Flutter 客户端负责界面、领域规则与数据管理。核心记账独立于服务器，iOS WidgetKit 与 Android RemoteViews 读取应用提交的本机摘要。

## 账本

SQLite 保存账本及流水。金额以币种最小单位存储，原币与基准币保留入账快照。分类、标签、预算、模板与周期计划按账本管理。

`domain.dart` 和领域模块负责金额、账期、预算等规则；`local_database.dart`、`data_store.dart` 和 `store.dart` 负责持久化与状态。流水和预算 UI 复用领域口径。

## 物品

`BelongingsStore` 使用独立 SQLite 数据库和内容寻址图片目录。物品、维修费用和图片独立于账本流水，不参与记账预算。日均成本按实际日历天数计算。

## 导出与恢复

CSV 用于流水交换；完整账本备份包含模板和周期状态，恢复创建副本。物品备份单独包含物品与照片。恢复时校验格式、引用与摘要，生成新的实体 ID，避免覆盖已有记录。

WebDAV 备份使用用户自己的 HTTPS 目录，上传后回读并核对哈希。凭据使用系统安全存储，备份不含凭据；备份内容目前不加密。

## 兼容与网络

保留旧账本和历史状态迁移逻辑，但核心离线使用不需要部署旧服务端。参考汇率、用户启用的 WebDAV、外部链接和官方 Android 更新通道可能使用网络。自行构建默认禁用官方安装包更新。
